# FAQ-бот для тестового хакатона

Консольный бот на Python, отвечающий на 5 основных вопросов о репетиции хакатона. Работает локально без использования внешних LLM API, нейросетей и RAG.

## Структура проекта
- `faq.txt` — База вопросов и ответов (время, команда, трек, сдача, призы).
- `main.py` — Скрипт бота с механизмом сопоставления ключевых слов и схожести фраз.
- `README.md` — Документация проекта.

## Быстрый запуск

Убедитесь, что у вас установлен Python версии 3.8 или выше.

Запустите бот командой в терминале:

```bash
python main.py
